# Terra receipt cutout

`terra-peek-receipt.png` is a transparent derivative for the chat receipt only.
The original approved cube and wordmark files are unchanged. The CSS backing is
separate so the character's full head can peek over it without a clipping mask.

Created with the built-in imagegen tool from `terra-cube-1080.png` on 2026-10-24
in response to ET's request for a peeking character with an uncropped head.

Prompt: preserve the recognizable lime rounded 3D cube, glossy black oval eyes,
white highlights, asymmetrical face orientation, clay texture and lighting;
remove the forest-green background, reconstruct missing boundaries consistently,
center the complete cube with transparent margins, and keep its full rounded
head visible. No mouth, limbs, extra features, text, badge or setting. The bean
backing is rendered in CSS, not baked into the asset.
