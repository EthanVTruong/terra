# Typography and historical reference

The released product and station lab use the system sans-serif stack already
present in their styles: `-apple-system, BlinkMacSystemFont, Segoe UI, sans-serif`.
No third-party font binary is distributed. Sizes, line heights and spacing from
the accepted layout are retained; glyph metrics vary with the operating system.

Earlier reference-fidelity screenshots and QA used the exact xVf asset served
by the inspected Grok Bot article on 2026-10-24. Its source and hash were recorded,
but no redistribution grant was recorded. Both bundled copies were removed for
the open-source release. Those older screenshots remain historical evidence,
not a statement about release typography or permission to redistribute the font.
